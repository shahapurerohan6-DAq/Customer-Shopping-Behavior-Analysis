# 📌 Project Overview

This project analyzes **3,900 customer shopping transactions** to understand purchasing behavior, customer demographics, subscription trends, product performance, and revenue patterns.

The complete analytics pipeline covers:

✅ Data Cleaning using Python

✅ SQL Business Analysis using PostgreSQL

✅ Interactive Dashboard Development in Power BI

- Identify top-performing product categories
- Compare subscriber and non-subscriber spending
- Segment customers based on purchase history
- Discover revenue trends
- Build an interactive dashboard for decision making
